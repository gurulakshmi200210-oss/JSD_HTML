OpenCV (Open Source Computer Vision Library): OpenCV is the primary tool for image pre-processing. It is used to resize images, remove background noise, and perform color- space conversions. Specifically, it converts images from RGB to HSV (Hue, Saturation, Value) to effectively isolate human skin tones from the background.  TensorFlow & Keras: These are high-level deep learning frameworks used to implement the Convolutional Neural Network (CNN). The CNN is responsible for "Object Classification"—identifying whether the uploaded garment is a top wear (shirt/t-shirt) or a bottom wear (trousers/skirt).
